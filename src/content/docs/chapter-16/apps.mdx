| Swedish | English | Example (Swedish) | Example (English) |
|---|---|---|---|
| **en app** | an app | Jag använder en **app** för att hålla reda på mina utgifter. | I use an app to keep track of my expenses. |
| **en appbutik** | an app store | Jag hittade programmet i en **appbutik**. | I found the program in an app store. |
| **en ikon** | an icon | Tryck på **ikonen** för att öppna appen. | Tap the icon to open the app. |
| **en funktion** | a feature | Appens nya **funktion** gör det lättare att dela bilder. | The app's new feature makes it easier to share photos. |
| **ett användarkonto** | a user account | Du behöver ett **användarkonto** för att spara dina inställningar. | You need a user account to save your settings. |
| **ett användarnamn** | a username | Välj ett **användarnamn** som är lätt att komma ihåg. | Choose a username that is easy to remember. |
| **ett lösenord** | a password | Byt **lösenord** om du tror att någon annan känner till det. | Change your password if you think someone else knows it. |
| **en inställning** | a setting | Du kan ändra **inställningen** för språk i menyn. | You can change the language setting in the menu. |
| **en avisering** | a notification | Jag stängde av **aviseringarna** eftersom de kom så ofta. | I turned off the notifications because they came so often. |
| **en uppdatering** | an update | Den senaste **uppdateringen** löste problemet med inloggningen. | The latest update fixed the login problem. |
| **en version** | a version | Den här **versionen** fungerar inte på min gamla telefon. | This version does not work on my old phone. |
| **en behörighet** | a permission | Appen ber om **behörighet** att använda kameran. | The app asks for permission to use the camera. |
| **en prenumeration** | a subscription | **Prenumerationen** förnyas automatiskt varje månad. | The subscription renews automatically every month. |
| **en säkerhetskopia** | a backup | Jag gör en **säkerhetskopia** så att jag inte förlorar mina filer. | I make a backup so I do not lose my files. |
| **ladda ner** | to download | Hon **laddade ner** appen innan resan. | She downloaded the app before the trip. |
| **installera** | to install | Det tar bara några minuter att **installera** programmet. | It only takes a few minutes to install the program. |
| **uppdatera** | to update | Kom ihåg att **uppdatera** appen för att få den senaste versionen. | Remember to update the app to get the latest version. |
| **avinstallera** | to uninstall | Jag **avinstallerade** appen eftersom jag aldrig använde den. | I uninstalled the app because I never used it. |
| **logga in** | to log in | Du måste **logga in** innan du kan se dina bokningar. | You have to log in before you can see your bookings. |
| **logga ut** | to log out | **Logga ut** från kontot om du använder en delad dator. | Log out of the account if you are using a shared computer. |
| **registrera sig** | to register | Nya användare kan **registrera sig** med sin e-postadress. | New users can register with their email address. |
| **tillåta** | to allow | Jag **tillåter** inte appen att spåra min plats. | I do not allow the app to track my location. |
| **dela** | to share | Med appen kan vi **dela** dokument med hela gruppen. | With the app, we can share documents with the whole group. |
| **synkronisera** | to sync | Kalendern **synkroniseras** automatiskt mellan mina enheter. | The calendar syncs automatically between my devices. |
| **användarvänlig** | user-friendly | Gränssnittet är **användarvänligt**, även för den som är ovan vid teknik. | The interface is user-friendly, even for someone who is not used to technology. |
