A conditional sentence describes a condition and what happens, may happen, or would happen if that condition is true. In Swedish, the condition is often introduced by **om** (“if”), and the result is in a main clause.

| Condition | Result | English |
| --- | --- | --- |
| Om jag får tid, | lagar jag middag. | If I have time, I’ll cook dinner. |
| Om det regnar, | stannar vi hemma. | If it rains, we’ll stay at home. |

The condition can come before or after the result. The choice of verb forms depends on whether the speaker presents the condition as a real possibility, an imagined situation, or something that did not happen.

## Real or open conditions

For a condition that is possible or realistic, use the present tense in the **om** clause. The result can be in the present, future, or imperative, depending on what you mean. Swedish normally uses the present tense—not **ska**—for a future event in the **om** clause.

| Swedish | English |
| --- | --- |
| Om du kommer tidigt, kan vi ta en kaffe. | If you come early, we can have a coffee. |
| Om jag hittar nycklarna, ringer jag dig. | If I find the keys, I’ll call you. |
| Om du blir sjuk, stanna hemma. | If you get sick, stay home. |
| Om tåget är försenat, väntar vi på stationen. | If the train is delayed, we’ll wait at the station. |

The present tense does not mean the condition is happening now. It can refer to the future because the event is still open or possible.

## Imagined or less likely conditions

To present a current or future situation as imagined, unlikely, or contrary to what is true, use a past-tense verb in the **om** clause. The past tense here does not place the condition in the past. The result often has **skulle** (“would”) followed by an infinitive.

> **om** + subject + past tense, **skulle** + subject + infinitive

| Swedish | English |
| --- | --- |
| Om jag hade mer tid, skulle jag lära mig italienska. | If I had more time, I would learn Italian. |
| Om hon bodde närmare, skulle vi ses oftare. | If she lived closer, we would see each other more often. |
| Om de vann på lotteri, skulle de resa jorden runt. | If they won the lottery, they would travel around the world. |

Common past forms in these hypothetical conditions include **hade** (“had”), **var** or **vore** (“were”), **kunde** (“could”), and **ville** (“wanted to”). **Vore** is especially common in the expression **om jag vore du** (“if I were you”); **om jag var du** is also used in everyday Swedish.

| Swedish | English |
| --- | --- |
| Om jag vore du, skulle jag tacka ja. | If I were you, I would accept. |
| Om han kunde, skulle han hjälpa oss. | If he could, he would help us. |

The choice between a present-tense condition and a past-tense hypothetical is about how the speaker views the situation, not simply when it will happen:

| More open possibility | More hypothetical |
| --- | --- |
| Om jag har råd, köper jag en ny dator. — If I can afford it, I’ll buy a new computer. | Om jag hade råd, skulle jag köpa en ny dator. — If I could afford it, I would buy a new computer. |
| Om hon kommer i kväll, blir jag glad. — If she comes tonight, I’ll be happy. | Om hon kom i kväll, skulle jag bli glad. — If she came tonight, I would be happy. |

For an uncertain future event, **om + skulle + infinitive** is also possible. It presents the event as a possibility that might arise:

| Swedish | English |
| --- | --- |
| Om du skulle behöva hjälp, kan du ringa mig. | If you should need help, you can call me. |

## Conditions about the past

To talk about an imagined past condition—something that did not happen—use **hade + supine** in the **om** clause. The supine is the form used after **har** or **hade**, such as **ätit** in **har ätit** (“has eaten”). The result commonly uses **skulle ha + supine**.

> **om** + subject + **hade** + supine, **skulle** + subject + **ha** + supine

| Swedish | English |
| --- | --- |
| Om jag hade vetat om festen, skulle jag ha kommit. | If I had known about the party, I would have come. |
| Om vi hade gått hem tidigare, skulle vi ha hunnit med bussen. | If we had gone home earlier, we would have caught the bus. |
| Hon skulle ha följt med om hon hade varit ledig. | She would have come along if she had been free. |

## Conditions with results in a different time

The condition and its result do not have to refer to the same time. For example, a past event can explain a present result. The forms show the time of each part:

| Swedish | English |
| --- | --- |
| Om jag hade lagt mig tidigare, skulle jag inte vara så trött nu. | If I had gone to bed earlier, I wouldn’t be so tired now. |
| Om jag inte vore så trött, skulle jag ha följt med i går. | If I weren’t so tired, I would have come along yesterday. |

## Word order

An **om** clause is a subordinate clause. In it, **inte** normally comes before the finite verb:

| Swedish | English |
| --- | --- |
| Om jag inte hittar vägen, frågar jag någon. | If I don’t find the way, I’ll ask someone. |
| Vi går ut om det inte regnar. | We’ll go out if it isn’t raining. |

When the **om** clause comes first, the following main clause begins with its verb, before the subject. This is called inversion:

| Condition first | Result first |
| --- | --- |
| Om bussen inte kommer, tar vi en taxi. — If the bus doesn’t come, we’ll take a taxi. | Vi tar en taxi om bussen inte kommer. — We’ll take a taxi if the bus doesn’t come. |
| Om jag hade pengar, skulle jag köpa den. — If I had money, I would buy it. | Jag skulle köpa den om jag hade pengar. — I would buy it if I had money. |

In the first sentence of each pair, the main clause begins **tar vi** or **skulle jag**. When the main clause comes first, it keeps ordinary subject–verb order. If **inte** is in the main clause, it normally follows the finite verb:

| Swedish | English |
| --- | --- |
| Om jag hade bil, skulle jag inte ta bussen. | If I had a car, I wouldn’t take the bus. |
| Jag skulle inte ta bussen om jag hade bil. | I wouldn’t take the bus if I had a car. |

## Other ways to express a condition

**Ifall** can replace **om** in many everyday sentences. It has the same word order and meaning, though **om** is more common:

| Swedish | English |
| --- | --- |
| Ring mig ifall du blir sen. | Call me if you’re going to be late. |

**Om inte** means “if not” and often translates naturally as “unless”:

| Swedish | English |
| --- | --- |
| Vi tar en promenad om det inte börjar regna. | We’ll go for a walk unless it starts to rain. |
| Om du inte skyndar dig, missar du tåget. | Unless you hurry, you’ll miss the train. |

**Såvida inte** also means “unless,” but it is more formal than **om inte**:

| Swedish | English |
| --- | --- |
| Vi öppnar inte fönstret, såvida det inte blir för varmt. | We won’t open the window unless it gets too warm. |

Do not confuse conditional **om** (“if”) with **om** meaning “whether.” In the second example below, the clause expresses uncertainty, not a condition:

| Swedish | English |
| --- | --- |
| Om det blir soligt, går vi till stranden. | If it gets sunny, we’ll go to the beach. |
| Jag vet inte om det blir soligt. | I don’t know whether it will get sunny. |
