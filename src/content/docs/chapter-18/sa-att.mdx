**Så att** connects a main clause to a clause that tells what someone intends to happen or what actually happens as a result. It often means **“so that”**; when it describes an actual consequence, it can also mean **“with the result that.”**

## Intended result

Use **så att** to explain the aim of an action. The clause after **så att** has its own subject and a finite verb (a verb marked for tense or used as a modal verb):

| Swedish | English |
| --- | --- |
| Vi skyddar skogen så att djuren kan överleva. | We protect the forest so that the animals can survive. |
| Jag skriver upp adressen så att jag inte ska glömma den. | I write down the address so that I won't forget it. |
| Hon talade långsamt så att alla skulle förstå. | She spoke slowly so that everyone would understand. |

The subjects in the two clauses may be the same or different. The purpose clause often includes a modal such as **kan** (“can”), **ska** (“will; should”), **skulle** (“would”), or **kunde** (“could”), but a modal is not required:

| Swedish | English |
| --- | --- |
| Jag stänger fönstret så att katten inte går ut. | I close the window so that the cat doesn't go outside. |
| Vi lämnade en lampa tänd så att huset såg bebott ut. | We left a light on so that the house looked occupied. |

If the purpose clause comes first, the main clause that follows has inversion: its verb comes before its subject.

| Swedish | English |
| --- | --- |
| Så att vi skulle hinna i tid tog vi en tidigare buss. | So that we would arrive on time, we took an earlier bus. |

## Word order after **så att**

The clause after **så att** is a subordinate clause. Its usual order is:

**så att + subject + (inte) + finite verb + the rest of the clause**

In subordinate clauses, **inte** normally comes before the finite verb. With a modal verb, it comes before the modal:

| Swedish | English |
| --- | --- |
| Vi satte upp ett staket så att barnen inte skulle gå ut på vägen. | We put up a fence so that the children wouldn't go out onto the road. |
| Jag sparar pengar så att jag kan köpa en cykel. | I'm saving money so that I can buy a bicycle. |

Do not use question order after **så att**: say **så att barnen inte skulle gå**, not **så att skulle barnen inte gå**.

## Actual consequences

**Så att** can also introduce a result that happened, rather than an intended aim. The surrounding context makes the meaning clear:

| Swedish | English |
| --- | --- |
| Det regnade hela natten, så att stigen blev lerig. | It rained all night, with the result that the path became muddy. |
| Dörren hade frusit fast, så att vi inte kunde komma in. | The door had frozen shut, so we couldn't get in. |

Compare an intended result with an actual one:

| Swedish | English |
| --- | --- |
| Vi tog med en karta så att vi inte skulle gå vilse. | We brought a map so that we wouldn't get lost. |
| Vi gick vilse, så att vi kom fram sent. | We got lost, so we arrived late. |

For a direct cause, use **eftersom** or **därför att** (“because”), not **så att**. The cause explains why something happened; **så att** points to the aim or consequence:

| Swedish | English |
| --- | --- |
| Vägen var avstängd eftersom ett träd hade fallit. | The road was closed because a tree had fallen. |
| Ett träd hade fallit över vägen, så att trafiken stoppades. | A tree had fallen across the road, so traffic was stopped. |

## **Så … att** for degree

Do not confuse the conjunction **så att** with the pattern **så + adjective or adverb + att**. In this pattern, **så** means “so” or “such,” and the **att** clause gives the result of that degree. An adjective or adverb comes between **så** and **att**:

| Swedish | English |
| --- | --- |
| Vattnet var så kallt att vi inte kunde bada. | The water was so cold that we couldn't swim. |
| Hon pratade så tyst att jag inte hörde henne. | She spoke so quietly that I couldn't hear her. |
| Det fanns så många gäster att alla stolar blev upptagna. | There were so many guests that all the chairs were taken. |

Here, **så kallt att** describes how cold the water was; it is not a purpose clause. When there is no adjective, adverb, or quantity between **så** and **att**, **så att** usually introduces a purpose or a consequence directly: **Vi satte oss nära dörren så att vi kunde gå tidigt** (“We sat near the door so that we could leave early”).
