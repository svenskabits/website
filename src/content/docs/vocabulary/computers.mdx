## Computer equipment

| Swedish | English | Example (Swedish) | Example (English) |
|---|---|---|---|
| **en dator** | a computer | Jag använder **datorn** för att arbeta hemifrån. | I use the computer to work from home. |
| **en bärbar dator** | a laptop | Hon tar med sig **den bärbara datorn** till biblioteket. | She brings her laptop to the library. |
| **en stationär dator** | a desktop computer | **Den stationära datorn** står kvar på kontoret. | The desktop computer stays at the office. |
| **en surfplatta** | a tablet | Han läser tidningen på **surfplattan** varje morgon. | He reads the newspaper on the tablet every morning. |
| **en skärm** | a screen / monitor | Jag kopplade en extra **skärm** till datorn. | I connected an extra monitor to the computer. |
| **ett tangentbord** | a keyboard | **Tangentbordet** fungerar inte efter att jag spillde kaffe på det. | The keyboard does not work after I spilled coffee on it. |
| **en mus** | a mouse | Du kan markera texten med **musen**. | You can select the text with the mouse. |
| **en skrivare** | a printer | **Skrivaren** behöver nytt bläck. | The printer needs new ink. |
| **ett USB-minne** | a USB flash drive | Jag sparade dokumenten på **USB-minnet**. | I saved the documents on the USB flash drive. |

## Internet and security

| Swedish | English | Example (Swedish) | Example (English) |
|---|---|---|---|
| **ett nätverk** | a network | Datorn ansluter automatiskt till företagets **nätverk**. | The computer connects automatically to the company's network. |
| **en internetuppkoppling** | an internet connection | Vi behöver en stabil **internetuppkoppling** för videosamtalet. | We need a stable internet connection for the video call. |
| **ett användarkonto** | a user account | Du behöver ett **användarkonto** för att komma åt tjänsten. | You need a user account to access the service. |
| **ett användarnamn** | a username | Skriv ditt **användarnamn** i det första fältet. | Type your username in the first field. |
| **ett lösenord** | a password | Välj ett **lösenord** som är svårt för andra att gissa. | Choose a password that is hard for others to guess. |
| **logga in** | to log in | Jag måste **logga in** igen eftersom sessionen har gått ut. | I have to log in again because the session has expired. |
| **logga ut** | to log out | **Logga ut** när du använder en offentlig dator. | Log out when you use a public computer. |
| **en säkerhetskopia** | a backup | Vi gör en **säkerhetskopia** av filerna varje natt. | We make a backup of the files every night. |
| **ett virus** | a virus | Ett **virus** kan skada filer på datorn. | A virus can damage files on the computer. |

## Problems and fixes

| Swedish | English | Example (Swedish) | Example (English) |
|---|---|---|---|
| **ett felmeddelande** | an error message | Ett **felmeddelande** visas när jag försöker öppna filen. | An error message appears when I try to open the file. |
| **fungera** | to work / function | Skrivaren **fungerar** inte trots att den är påslagen. | The printer does not work even though it is turned on. |
| **hänga sig** | to freeze | Datorn brukar **hänga sig** när jag har för många program öppna. | The computer tends to freeze when I have too many programs open. |
| **krascha** | to crash | Programmet kan **krascha** om filen är skadad. | The program may crash if the file is damaged. |
| **starta om** | to restart | Prova att **starta om** datorn innan du kontaktar supporten. | Try restarting the computer before you contact support. |
| **en supportavdelning** | a support department | Jag kontaktade **supportavdelningen** när jag inte kunde komma åt kontot. | I contacted the support department when I could not access the account. |
