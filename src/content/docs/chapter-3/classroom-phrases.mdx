## People

| Swedish | English | Example (Swedish) | Example (English) |
|---|---|---|---|
| **en lärare** | a teacher | **Läraren** skriver på tavlan. | The teacher writes on the board. |
| **en elev** | a student | **Eleven** läser en text. | The student reads a text. |
| **en klass** | a class | **Klassen** börjar klockan nio. | The class starts at nine. |

## Words and classroom materials

| Swedish | English | Example (Swedish) | Example (English) |
|---|---|---|---|
| **ett ord** | a word | Jag stavar **ordet** långsamt. | I spell the word slowly. |
| **en fråga** | a question | Eleven ställer **en fråga**. | The student asks a question. |
| **ett svar** | an answer | Hon skriver **ett svar**. | She writes an answer. |
| **en mening** | a sentence | Vi läser **meningen** högt. | We read the sentence aloud. |
| **en text** | a text | Vi läser **en text**. | We read a text. |
| **en sida** | a page | Vi läser **sidan** tillsammans. | We read the page together. |
| **en bok** | a book | **Boken** ligger på bordet. | The book is on the table. |
| **en penna** | a pen | Jag skriver med **en penna**. | I write with a pen. |
| **en tavla** | a board | Läraren skriver på **tavlan**. | The teacher writes on the board. |

## Classroom actions

| Swedish | English | Example (Swedish) | Example (English) |
|---|---|---|---|
| **förstå** | to understand | Jag **förstår** frågan. | I understand the question. |
| **fråga** | to ask | Eleven **frågar** läraren. | The student asks the teacher. |
| **svara** | to answer | Eleven **svarar** på frågan. | The student answers the question. |
| **upprepa** | to repeat | Läraren **upprepar** ordet. | The teacher repeats the word. |
| **lyssna på** | to listen to | Vi **lyssnar på** läraren. | We listen to the teacher. |
| **läsa** | to read | Jag **läser** texten högt. | I read the text aloud. |
| **skriva** | to write | Jag **skriver** mitt namn. | I write my name. |
| **prata** | to speak | Vi **pratar** svenska i klassen. | We speak Swedish in class. |
| **säga** | to say | Hon **säger** ordet tydligt. | She says the word clearly. |
| **hjälpa** | to help | Läraren **hjälper** eleven. | The teacher helps the student. |

## Helpful words

| Swedish | English | Example (Swedish) | Example (English) |
|---|---|---|---|
| **långsamt** | slowly | Läraren pratar **långsamt**. | The teacher speaks slowly. |
| **igen** | again | Vi läser texten **igen**. | We read the text again. |
