# Swedish Course: One Path, 20 Chapters

A single learning path from A1 to B2. Each chapter has several pages, and each page covers one topic.

**Page tags**

- **G** = Grammar
- **V** = Vocabulary
- **P** = Pronunciation
- **A1 / A2 / B1 / B2** = CEFR level

A page's level can sit one step off its chapter's level when the topic naturally belongs a little earlier or later (for example, a B1 chapter that contains one A2 page).

**Chapter titles** are sentences or questions that use the chapter's key grammar, so the title itself previews what the chapter teaches.
